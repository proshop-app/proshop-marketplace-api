База — неизменяемый `testdata/release-9.json`; непринятый первый черновик 10
также проверен отдельно. Исторические решения о книгах и поле ниже заменены

## Источники и метод

Проверены EN/RU-снимки атрибутов, pools и taxonomy-bindings.v7 из
uno-reference-data, доступные только для чтения. В этих локальных Shopify
JSON находятся атрибуты, не полное дерево категорий. Поэтому для проверки
ассортимента дополнительно прочитан официальный
[архив категорий Shopify 2026-10](https://github.com/Shopify/product-taxonomy/releases/download/v2026-10/categories.en.json.gz)
(MIT): 26 вертикалей, 64292 записи; SHA-256 распакованного JSON
`51a1542bfc8ed0cbe180f05ef279f92a5bc2c4d63ee8b2c62e33abb31672997f`.
Архив и рабочие выгрузки остаются в `.scratch/`, в поставку не входят.
Первоначальная дополнительная копия dist имела версию 2026-11-unstable;
итоговый контроль проведён по закреплённому выпуску 2026-10.

Для российского ассортимента использованы открытые страницы
[каталога Ozon](https://www.ozon.ru/category/) и
[каталога Яндекс Маркета](https://market.yandex.ru/catalog), без обхода защит,

материал и цвет не размножают виды; тема и аудитория теперь образуют навигационные разделы.

Исключены также заказные технологические линии, недвижимость, права/услуги,
отдельные от продаваемой лицензии или сертификата. Это граница модели розничного
товара. Наличие листа регулируемого ассортимента не запускает его продажу:
для новых препаратов, табака, алкоголя, животных, транспорта и сертификатов
задана ручная модерация; решение о допуске остаётся у владельца.

## Атрибуты и связи

| Найденный класс дефекта | Решение и проверка |
|---|---|
| Один код смешивал размер, диапазон, область или пол с возрастом | Исторические определения сохранены; активные коды и контекст преобразования перечислены в миграции |
| Строки-фасеты без словаря | Каждая активная фильтруемая строка получила ссылку; 8 свободных полей имеют причину и facet=false |
| Названия без объекта, повтор нормализованного имени, число без единицы | Go-аудитор запускается загрузчиком, check и тестами; повреждённые варианты проверены отрицательными тестами |
| Схема телефона на ремешках, ткани на запонках, застёжка сумки на брелоке | Предметные схемы и наследуемые общие наборы; отдельные регрессионные проверки чужих полей |
| Слияние схем только по равенству списков полей | Отменено: общий набор геометрии наследуется, предметные схемы не переименовываются в чужой объект |
| purpose отсутствовал у 290/604 Piquadro | Дефект обязательности: вид изделия уже определяет функцию, старое поле исключено |
| size_standard отсутствовал у 640 обувных карточек Noone | Система необязательна, имеет словарь; размерная маркировка остаётся осью SKU |

Матрица всех листьев воспроизводится `taxonomy check --review`; полный просмотр
исходных 29 направлений и контроль трёх приоритетных деревьев использованы для
правок выше. Выгрузки находятся в `.scratch/taxonomy/`, а не в сопровождаемых docs.

## Проверка на магазинах

Проверены 604 + 294 + 1000 карточек и 66 + 28 + 97 исходных разделов.
Карточки без листа и двойные назначения — 0. Смешанные витринные разделы
разносятся по товарам; неполные разделы и противоречия перечислены поимённо во
внешнем `demo-shops/taxonomy-fit/taxonomy-demo-fit.md` и JSON рядом.
Не проверены установка новых словарей, нормализация всех значений и все SKU:
проверка наличия обязательного размера на карточке использует явные варианты.
