# Оси вариантов площадки

Карточка GET /api/v1/catalog/offers/{offerId} содержит только
`variants: { groupId }`. Группа загружается отдельным запросом
GET /api/v1/catalog/variants/{tenantId}/{groupId} перед рендером витрины.

Запрос возвращает массив `options: [{ key, code, name, values }]` в порядке осей
магазина и все видимые предложения
группы продавца с доступным ценовым профилем. Значения options упорядочены
таксономией, затем позицией участника и id. Дубликаты сочетаний остаются
в items; целевой товар выбирает helper витрины. Участник без метаданных осей
сохраняется в items с пустыми attrs и не добавляет значений в options.
Потолок поисковой группы прежний: 200 предложений, затем truncated=true.

Цены числовыми рублями, с X-Marketplace-Money-Unit: RUB и контекстом покупателя.
Ответ группы private, no-store. При холодном отсутствии персонального профиля
общий helper `priceOffer` в application/catalog/pricing.go перечитывает публичную
проекцию каждого предложения, проверяет видимость и выбирает публичный профиль.
Карточка Offer пользуется тем же helper; её прежний порядок чтений и отказов сохранён.
При наличии контекста цена, как и в карточке, выбирается из профилей индекса.

Входное событие и сохранённый JSONB читаются одним Variants.UnmarshalJSON:
axis + value превращаются в axes из одного элемента; наружу только axes.
Неизвестные поля игнорируются, включая поля внутри осей. Разбор отклоняет
смешение форм и неполную старую форму; проверки значений остаются в Validate.
Обе формы вместе, пустой список, повтор ключа, более восьми осей и значение
длиннее 1024 символов отклоняются при приёме события. Несистемные оси,
пустые и многозначные значения по-прежнему не передаются магазином.

Прочие места: postgres/products.go (JSONB), searchapi/types.go и document.go,
application/catalog/indexing.go, application/fake/index.go и index-group.go
переносят общий тип; их группировка и сортировка позиций не менялись.
Модерационные снимки читают тот же доменный тип; фикстуры сравнений и
model-keys_integration_test переведены на axes. Корзина и выдача не читают
значения осей; deploy-пакеты чистой базы не содержат variants. tileKey,
variantsId, модель групп магазина, схема БД и версия поискового контракта прежние.
