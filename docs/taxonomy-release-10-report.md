## Главные решения

- Рабочая, медицинская, поварская, сервисная и форменная одежда восстановлена по предметам, без половых копий. Школьная — по предметам внутри девочек/мальчиков. Для обычной офисной одежды рекомендация продавца не создаёт форму.
- Бриджи, капри, джеггинсы, смокинги и кигуруми — самостоятельные виды с границами. Беременность, кормление и большая размерная группа не новые ветки.
- Спорные аудиторные виды оставлены осознанно по изготовителю/посадке: подростковые бюстгальтеры, детские шубы/косухи/тренчи; мужские шубы и спортивные легинсы; мальчиковые колготки/легинсы. Детских корсетов нет.
- Уход за одеждой разделён между существующей техникой, хозяйственными расходниками, галантереей и шитьём по функции. Дубли не создавались.
- Атрибуты пола/возраста остаются необязательными словарными данными; веток унисекс нет. Новых исключений повторных имён нет.
- Новые словарные ссылки: **нет**. По-прежнему 178 базовых ссылок и 18 контекстных `compat_*`: 17 closed, 179 open. Определения семи новых полей не создают словарных значений.

## Схемы и обязательность

Одежда и школьная/профессиональная форма требуют маркировку размера; колпаки — `headwear_size_label`, гамаши — `size_clothing_label`. Деталь СИЗ не наследует размер тела. Размерная ось остаётся вариантообразующей. Парео имеет собственную схему без признака доступа к груди. Для двигателя малой техники обязателен объём цилиндров; электрическая потребляемая мощность не подставляется вместо механической выходной мощности.

Электростанция требует `battery_energy` и `ac_output_w`, автоклав — `capacity_l`, электротекстиль — `length/width`; пассивный автомобильный динамик — `speaker_impedance`, усилитель — `audio_output_w`. Носки/чулки не наследуют признаки материнства, поясное бельё — доступ к груди. Матрица новых листьев со схемами просмотрена по направлениям, полное дерево одежды — ниже. У общих схем обязательность не усиливалась для чужого предмета.
