в эту поставку не входят. Покрытие задано таблицей; категории за её пределами

Схемы — внутренний способ избежать дублирования файлов данных. API отдаёт
уже развёрнутые атрибуты категории; отдельной сущности типа товара нет.

Для брендов, моделей, кодов производителя и открытых классификаций используется
строка. Числа имеют явную единицу, перечисления ограничены известным набором.
Код/имя/тип/единица атрибута одинаковы во всех схемах; обязательность относится
к привязке в схеме. Бренд не обязателен для безбрендовых товаров.

Данные — собственный начальный каталог uno. Его охват явно ограничен
перечисленными направлениями; расширения выпускаются следующими поставками.


## Поставка 2: варианты и GTIN (29.10.2026)

219 атрибутов и 167 значений в 142 схемах. Необязательный строковый `gtin`
добавлен рядом с брендом во все схемы. `color.valuesMeta` содержит образцы.
Размерные перечисления `size_clothing`, `size_shoes_eu`, `size_kids_height`,
`size_ring` согласованы владельцем; прежний строковый `size` сохранён.
Подробности поставки и отката — [marketplace-variants.md](marketplace-variants.md).

Три новые схемы поставки 2: `ring`, `clothing_kids`, `outerwear_kids`.
В `categories.json` кольца используют `ring`, детская одежда — `clothing_kids`,
детская верхняя одежда — `outerwear_kids`.
