# Импорт словарей для публикации таксономии

Выпуск 10 расширил набор базовых и контекстных привязок. Для текущего запуска
используется актуальная таксономия и полный пакет из uno-reference-data, а не
историческая последовательность частичных файлов выпуска 10.

1. Применить миграции площадки.
2. Оператором импортировать `exports/marketplace-bootstrap.json` из uno-reference-data
   по [контракту v2](reference-import.md). CLI: `marketplace reference import --file <пакет.json>`.
3. Проверить необходимые заголовки, kind и confirmed-значения перечислений.
   Критерии — [taxonomy-dictionaries-needed.md](taxonomy-dictionaries-needed.md).
4. Опубликовать актуальную таксономию с предусмотренной проверкой версии и
   подтверждением замены категорий.

Выпуски словарей независимы от выпуска таксономии. Изменившийся пакет должен
иметь следующий номер для каждого затронутого словаря. Прежние частичные экспорты
формата v1 больше не принимаются. Импорт не меняет привязки таксономии и не
подтверждает кандидатов автоматически. Перезапуск API ничего не загружает.

На стенде старый Helm Job `marketplace-reference` необходимо отключить до обновления
образа. Словарей в образе нет; загрузка выполняется оператором.
