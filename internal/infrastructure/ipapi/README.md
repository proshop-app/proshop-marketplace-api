# Определение города

Используется источник витрины магазина — ip-api, без блокировки отрисовки страницы.
Успешный ответ по IP хранится сутки, пустой — пять минут. Ошибка по IP хранится
пять секунд и возвращается как ошибка, а не как «город не найден». После HTTP 429
общая пауза новых обращений — минута (полное окно квоты); она разделяется через
Redis между процессами. Процесс, получивший 429, соблюдает паузу и при отказе Redis.
Тёплые успешные ответы остаются доступны во время паузы. Отмена запроса не кэшируется.
При отказе Redis общий кэш недоступен, остаётся локальная пауза получившего 429 процесса.

[Официальный договор ip-api](https://ip-api.com/docs/api:json): квота общая для
исходящего IP, 45 запросов в минуту. До исчерпания квоты новый IP покупателя всё ещё
требует внешнего запроса.
